How to replace a picture

  1. Open the Assets Folder button above.
  2. Click Add file → Upload files in GitHub.
  3. Upload your image using the exact filename shown above.
  4. Commit the change. GitHub Pages will update automatically after deployment.
  5. For new projects, simply send the images and details to ChatGPT; I can handle the page structure and text.
