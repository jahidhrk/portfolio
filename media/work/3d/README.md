# 3D Modeling & Layout — Video Assets

Upload each video/poster to this folder in the repository. The portfolio references these paths directly; there are no sample or fabricated videos.

| Project | Video | Optional poster |
| --- | --- | --- |
| Shop / Retail Layout | `shop-layout-01.mp4` | `shop-layout-01-poster.webp` |
| Event Booth / Exhibition Layout | `event-booth-01.mp4` | `event-booth-01-poster.webp` |
| Display Stand & Marketing Equipment | `display-stand-01.mp4` | `display-stand-01-poster.webp` |

Use MP4 with H.264 video (and optional AAC audio) for broad browser support, and web-optimized resolution and bitrate. Keep the original orientation. Videos attempt muted autoplay when visible, loop, and include play/pause and mute/unmute controls. Without an uploaded video the project displays a clean placeholder, not an invented preview. Posters are optional; add the matching image for a richer fallback.

To add a project or change a title, description, problem, work, result, video path, or poster path, edit the `modeling.projects` data array in `work.html`. To replace a video without changing code, upload a file using the exact filename listed above.
